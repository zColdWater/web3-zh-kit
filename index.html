接入 CI / 命令行 GitHub Action · CLI · x402

把检查放进每个 PR：语言包被译坏（占位符丢了、地址被改、链接被换）时直接标红。零依赖，只用 runner 自带的 Node。

name: zh-l10n
on: [pull_request]
jobs:
  qa:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: zColdWater/web3-zh-kit@v0.2.0
        with:
          source: locales/en.json
          target: locales/zh-CN.json locales/zh-TW.json   # 也可以写 locales/zh*.json
          min-score: 90        # 可选：低于 90 分算失败；不填则只在有 error 时失败

结果会写进 job summary，error / warning 以注解形式标在文件上。命令行：node zhlint.js check en.json zh-CN.json --format md。还可以打包成 x402 付费端点挂进网关，见 README。

  • 占位符 / 标签 / 代码：{address} 被译成 {地址}、%s 丢失、<0>…</0> 消失、ICU plural 结构被破坏
  • 链上数据：0x 地址、哈希被截断，ENS 名称、URL 被换
  • 术语：175 条，附 94 条已知误译（gas→汽油、seed phrase→种子短语、vesting→背心、mint→薄荷……）
  • 简繁混用、两岸用语、中文排版；规则全部确定性，不调用任何 LLM
